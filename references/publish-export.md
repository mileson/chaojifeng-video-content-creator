# 发布导出

A-Roll 清洗、粗剪或特效叠加轨完成后，做最终包装时读取本文件。

## 发布模式

| 模式 | 适用场景 | 输出 |
| --- | --- | --- |
| subtitle-only | 用户只要字幕/SRT/ASS | 字幕文件，可选硬字幕 MP4 |
| cover-metadata | 默认 MP4 封面模式 | 带 attached picture 元数据的 MP4 |
| first-frame | 用户希望播放第一帧就是封面 | 封面烧进开头帧的 MP4 |
| intro | 用户明确要保留片头卡 | 带片头段的 MP4 |
| package-only | 剪辑已确认，只重渲染包装/码率/封面 | 复用之前的 `edit_decisions.json` 边界 |

默认使用 MP4 attached cover metadata，让播放器打开时有封面，但实际播放从真实视频帧开始。

## 发布目录

在项目 `视频剪辑明细/publish/` 下创建版本目录。字幕制作过程、检查、当前发布数据和回执留在明细内；最终封面交付根目录 `封面图/`，工作台交付根目录 `<主题名>-视频预发布工作台.html`，发布文案交付根目录 `【发布文案】<主题名>.md`；验证通过的成片另行交付到根目录 `【成片】<主题名>.mp4`，同步交付 `【逐字稿】<主题名>.srt`。命名、同名文件处理和迁移按入口工程契约执行：

```text
<项目目录>/视频剪辑明细/publish/v001/
├── final.mp4
├── final.srt
├── final.ass
├── edit_decisions.json
├── hidden_speech_review.md
├── hidden_speech_review.json
├── checks/screen_review.json       # 含屏录时：地址、误遮与冗余动作审计
├── review_draft.md
├── transcript.raw.json
├── transcript.normalized.json
├── check_first_frame.png
├── check_subtitle_frame.png
├── check_cover_attachment.png
└── publish-notes.md
```

只有本版本实际运行了 ASR，才把原始 ASR JSON 和归一化转写放进发布目录；如果沿用上游 `aroll/` 产物，在 `publish-notes.md` 写清来源路径。`hidden_speech_review.md` 和 `.json` 即使没有问题也要生成，写明“未发现隐藏口播词”。

## 验证

说完成前先检查：

- 用 `ffprobe` 或等价工具确认时长、编码、分辨率、视频/音频流。
- 使用封面元数据时，检查封面附件。
- 抽第一帧，确认播放起点正确。
- 抽代表字幕帧，确认可读性。默认样式还要确认背景为 `#FF8920`、文字为 `#101820` 黑字白色圆润描边、圆角率 25%，且文字在橙色背景内垂直居中、上下留白一致。
- 检查一行与两行字幕各至少一帧，确认容器随内容收缩，没有直角背景、描边尖角、文字贴边或遮挡主体信息。
- 检查相邻中文字符没有因白描边连成一片；默认字距应为设计画布上的 `8px`，并以相邻白色描边之间存在可见的橙色细缝为准，且橙色容器已同步扩宽。
- 默认样式还要检查设计画布字号为 `50px`、白描边为 `3.25px`、单行最多 23 个字符；一行和两行字幕都不能溢出橙色容器。
- 全量检查最终 SRT 每条/每行及 ASS 文字层每个 `\N` 分行的尾部，确认没有 `，。！？；：、…` 或英文对应符号；忽略 ASS 控制标签和背景绘图层。检查字幕条目数量、口播文字与起止时间未被标点清理改动，并记录检查结果。
- 标点清理后必须重新烧录 MP4；至少抽查一行、两行及原先带尾部标点的字幕，文件检查通过不能代替成片检查。
- 检查最终文件大小。
- 将通过检查的版本成片复制到项目根目录 `【成片】<主题名>.mp4`，核对两份文件 SHA-256 相同；原片与原始工程保持原有位置。
- 在成片同级交付 `【逐字稿】<主题名>.srt`：优先复用已校正的完整成片字幕；缺失时使用现有本地转写工具，按入口规则记录来源和不确定内容。检查编号、文本非空、时间有效且有序、末条不超成片时长，以及与版本包 SRT 副本指纹一致。成片时间轴变更后逐字稿必须同步更新。
- 用当前最终发布选择汇总根目录 `【发布文案】<主题名>.md`，核对公共标题、正文及逐平台标题与已选标签一致，内容修改时同步更新。
- 用户确认封面后，按入口工程契约清理未采用的中间图片；先核对最终文件指纹、封面元信息与当前引用，不影响原始素材、图册模板或历史回执。
- 工作台和发布选择使用根目录成片的实际路径及预览 URL，最终封面引用根目录 `封面图/`，检查资料引用明细内路径；逐一确认当前引用存在。历史回执不改写，不因目录调整重复上传。
- 条件允许时，播放或抽查一段 mux 后的视频。
- 如果使用字幕或清洗决策，确认最终字幕没有隐藏真实说出口但未剪掉的词。
- 含屏录时按 `screen-recording-qa.md` 检查实际导出的 MP4：地址栏、左下角悬停链接、正文中的 `HTTP/HTTPS`、URL 与路径没有漏遮；每段遮罩还要检查无地址负样本，防止黑条或涂抹持续盖住页面。
- 含屏录且有画面动作裁剪时，检查剪口两侧的页面状态、有效口播和字幕；时间轴移动后核对全部相关遮罩区间。把候选、决策、检查帧和未验证处写进 `checks/screen_review.json` 或等价审计文件。

## 发布说明

`publish-notes.md` 应包含：

- 源视频。
- 字幕/ASR 来源、根目录逐字稿路径、对应成片时间轴及尚未校准的内容。
- 剪辑强度：conservative / standard / aggressive。
- 字幕样式。
- 封面模式。
- 根目录最终文件、版本包成片路径及一致的文件指纹。
- 剪辑决策文件。
- 隐藏口播检查。
- 已通过检查。
- 含屏录时的地址漏遮/误遮及多余画面动作审计结果。
- “我没有验证的部分”。

最终给用户的状态汇报要短、实用、可继续操作。

## 自动套餐交接

auto-package 在成片导出后继续执行 [auto-package.md](auto-package.md) 的画册封面和工作台步骤。MP4 内嵌封面元数据与平台独立封面分别处理；平台封面以最终工作台选择为准，封面改动不触发重新剪辑。

## 导出成片的自动风险复检

交付前执行入口的风险审查：检查实际成片音频、完整 SRT/ASS、烧录字幕及演示画面，对稿件预检不能代替导出后检查。复用已有转写和屏录检查帧，按本 Skill 的本地风险审查合同记录真实时间段、抽样范围和缺口到 `process_root/checks/distribution-risk-video.md`。如调整口播、字幕或画面，先复查受影响区间及相邻剪口再更新状态。

`publish-notes.md` 引用该报告，记录未处理／已接受风险及未验证范围。无命中静默完成原流程；有命中才主动列风险与改法，涉及已确认语义或发布决策时等待相关选择，不要求用户确认普通自检。不得把文件检查或经验提示描述为平台审核通过。
