# 限流与风控风险自检知识

此文件是 `chaojifeng-video-content-creator` 自带的风险知识，由本 Skill 本地读取，独立分发时随整个 Skill 目录携带。自检由 Agent 自动完成；不要求用户确认开始检查，无命中时静默继续。本文用于发现可审查的风险线索，不是平台禁词表，也不预测流量。

## 审查重点与维护

- 实际审查重点为 R01/R02/R04：音频、字幕和演示画面；强调真实成片时间段、音画一致、补录／剪辑的语义保护与局部遮盖验收。
- 本文件与同目录 [distribution-risk-review.md](distribution-risk-review.md) 构成本 Skill 的自检规则。已有真实检查报告可引用，缺少时记录范围，不要求安装其他工具才能完成本职责检查。
- 新增经验标注来源、适用条件及验证程度，新增官方规则保留一手依据；复用检查前先核对本文件内容是否有变化。
- 独立分享时包含本 Skill 的 `SKILL.md` 和整个 `references/` 目录；只复制入口文件不等于完整分发。风险自检的独立性不取消原有媒体生成、发布或其他制作能力的工具依赖。

## 七类检查项

| ID | 载体 | 检查的可观察内容 | 建议方向 | 依据与边界 |
| --- | --- | --- | --- | --- |
| R01 | 口播／音频 | 直接喊工具名、开场用品牌作卖点、反复宣传品牌；口述网址、联系方式或站外领取指令 | 非必要品牌表达可建议换成准确功能或场景；已录制时建议补录、授权配音或同步剪辑 | S1 经验提示；不能仅靠字幕判断实际音频，也不能删除必要产品身份使教程无法理解 |
| R02 | 字幕 | 软件中英文名、品牌堆叠、联系方式、外链与夸大承诺；SRT、ASS、重点字幕与实际烧录画面 | 建议与拟修改口播同步调整；字幕校正只修识别错误，不伪装音频内容 | S1 经验提示；禁止音频仍念品牌而字幕换成代称后声称风险消除 |
| R03 | 封面 | 大字工具名、占据视觉中心的大 Logo、官网网址、二维码；截图内残留标识 | 优先突出实际痛点、使用场景或有证据的结果；减少非必要标识或重新布局 | S1 经验提示；无需一律去品牌，小图标也不能称为规避审核的安全办法 |
| R04 | 演示界面 | 持续显露品牌、顶部标题栏、地址栏、正文网址、悬停链接及二维码 | 按实际需要建议裁切或局部遮盖，保留关键操作与真实证据；变动后复查漏遮、误遮 | S1 经验提示；不为隐藏品牌遮掉演示关键事实，地址隐私检查沿用视频现有规则 |

| R07 | 话题标签 | 产品标签、品牌标签堆叠、不相关活动、失效活动、为凑数量添加标签 | 提供与内容和目标平台匹配的动作／用途标签；沿用实时目录、容量与证据筛选 | S1 经验提示；文中话题只是历史示例，不默认有效或有流量；保留既有核心产品必选规则，冲突须列明 |

## 平台适用范围

S1 对小红书的体感较严格，对抖音描述为也会抽检，对 B站、视频号、快手描述为较宽松；这只是作者体验，不代表当前政策或稳定排序。上述五个平台出现七类可观察线索时可列为经验提示，优先注意小红书与抖音，但不能给其他平台免检。YouTube、X、公众号等没有被 S1 验证：不移植品牌限流结论，标明适用证据不足；仍检查实际导流、真实性与当前平台有证据的规则。平台未指定时完成载体检查并标明平台未知，不增加普通确认问答。

## 判断、通知与报告合同

1. 每次读取最新输入和目标平台；只检查当前 Skill 的职责范围。已有同输入指纹、规则版本与目标平台的检查可复用；没有变化不重复转写、截图、生成图片或启动浏览器。局部修订重新检查变化项、相邻剪口及跨载体一致性。
2. 命中须有具体原文、音频时间段或可见图像元素。品牌名称单次出现也可记为“经验提示”，但不能称为已违规、已限流或确定高风险。区分：官方规则命中（有当前适用的一手依据）、经验提示（S1）、待核验（可疑证据或适用范围不确定）。不同于风险类别的检查状态使用 reviewed / partial / not_checked / stale。
3. 自动执行检查，不让用户确认开始、结束或无风险通过。无命中时记录“本次已检查范围内未发现风险”，继续原流程；不额外主动通知，不宣称“不会限流”。部分检查、未检查及资料缺口记录范围，在既有未验证部分简短披露，不冒充通过；只有实际影响风控判断或后续动作的缺口才主动提示。
4. 有命中时主动给用户风险表，明确经验提示与官方规则的区别；列出具体改法及不改的影响边界，不夸大概率。继续不受影响的工作。检查本身不新增全流程审批；已确认文案、核心产品标签、口播语义、真实证据或已发布作品需要改变时，仅暂停相关修改／发布动作，等待用户选择保留或修改。已有针对该具体风险的选择持续有效，不重复确认。
5. 对尚未确认、由 Agent 新生成的候选，可以直接提供更稳妥的备选；保留原候选与命中记录，不静默改用户确认内容。不得因经验提示自动删除必选产品标签；用户选定替代方案后按各平台容量与当前选择同步。
6. 本 Skill 有项目时写入 process_root/checks/distribution-risk-video.md（默认 process_root 为项目的“视频剪辑明细”）。单独任务复用已有工作／检查目录；没有项目目录可在回复交付结果，不为自检新建项目或追问路径。无需新增 HTML、schema 或 CLI 字段。
7. 报告记录检查时间与时区、规则来源／版本、目标平台、输入路径与可得指纹／版本、已检查范围、未检查范围和原因、总体状态。无命中报告也保留；风险行标记 open / resolved / accepted / needs_check，保留前后版本和用户选择依据。修改后复查实际产物，未处理条目不能标 resolved。

## 发布后排查经验（仅用户要求时）

作者把发布 15–30 分钟零播放、推荐来源为 0、主页流量占比较高作为排查线索，并建议按“标题／正文／标签 → 封面 → 视频本体”逐步调整。沉淀为节省成本的排查顺序，不沉淀为诊断阈值：这些信号都不能单独确诊限流，先核对公开可访问状态、审核提示、统计延迟、采样窗口和账号通知；70%–80% 推荐占比也不是所有账号的健康标准。本文没有平台后台验证，不保证修改后半小时或一小时恢复。不得自动隐藏、删除、重发作品或批量操作；只提供建议，实际动作遵循用户明确授权。无必要不修改正常作品，不建立未经要求的持续监控。
