# 镜头语法速查（B-Roll 分镜必读）

> 译自 HyperFrames `step-3-storyboard.md` 的 shot grammar，按口播视频场景调整。

## 分镜是镜头（Shot），不是版面（Layout）

写画面描述时用镜头语言（推、拉、摇、移、聚焦），不要写"左边放一个卡片，右边放文字"这种网页版面语言。每一镜先回答：**这 3-5 秒观众该注意到什么、感受到什么？**

## 六种景别

| 景别 | 用于 | 画面占比 |
|------|------|---------|
| 大特写 | 单个数字 / 按钮 / 一行代码 / 光标，就它一个主体 | 主体占 60-90%，其余虚化或不存在 |
| 特写 | 一个 UI 区域（一列、一张卡、一个图表、一段代码块） | 主体占 40-60%，背后有景深层 |
| 中景 | 一段 UI（三列看板、三条消息的对话、双面板仪表盘） | 主体占 60-80%，相邻 UI 边缘入画 |
| 全景 | 完整界面总览——只在"全貌本身就是重点"时用 | 整体 70-90% 缩放 + 刻意留白 |
| 过肩 | 观众"站在用户身后"——前景手/设备，中景 UI | 前景占下 1/3，UI 占上 2/3 带视差 |
| 荷兰角 | 紧张、出问题了、"不对劲" | 画面倾斜 4-8° |

**全景陷阱**：每一镜都全景 = 截图幻灯片。产品演示类视频建议比例：特写+大特写 60% / 中景 20% / 全景 10% / 其他 10%。全景是稀缺的定场镜头，不是默认值。

## 镜头运动（每个 B-Roll 镜头至少一种）

- **推近 dolly in**：画面缓慢放大 1.0→1.08，带轻微位移——聚焦、强调
- **拉远 dolly out**：1.15→1.0，揭示更多上下文——展开、总览
- **快推 push**：0.5 秒内 1.0→1.05——关键时刻的"咚"
- **视差摇移 parallax pan**：前后景不同速反向漂移——空间感
- **环绕 orbit**：主体 3D 旋转或镜头绕主体——展示物件
- **变焦失焦 rack focus**：焦点从一个元素移到另一个——注意力转移

静止画面上限 ~2 秒；超过就加镜头运动或新元素入画。

## 运动量化下限（视频尺度可见性）

- 位移 ≥30px、缩放变化 ≥0.05、透明度变化 ≥0.5
- ±1-2px 的"呼吸"动画在视频里等于静止，不算运动

## 节奏声明

排完分镜后声明整条节奏，例：`快-快-慢-快-转场-定`。钩子镜头是全片最有野心的一镜，不是最温和的。结尾 CTA 镜头要有画面事件（logo 入场、数据汇总动画），台词结束后只保留 2-3 秒，不拖。
