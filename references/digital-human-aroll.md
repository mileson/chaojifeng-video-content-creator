# 数字人口播 A-Roll 与可编辑工程

这是 `chaojifeng-video-content-creator` 阶段 5.5 的可选入口。真人拍摄仍按原阶段 6-8 执行；拿到可用的数字人源片后，两条路径汇合。

## 输入与授权

1. 读取 `SCRIPT.md`、`STORYBOARD.md` 和现有品牌/视觉基线。数字人讲述的第一人称事实只能来自已核实材料，不从照片推断经历或声纹。
2. 用本人已授权的清晰正面照、视频帧或平台现有专属形象。确认肖像创建和使用授权；克隆本人声音必须另有明确授权。未克隆声音时标记为“平台预设音色”。
3. 记录平台、形象名称、源文件路径、脚本文本的哈希、音色类型、画幅、目标分辨率和生成时间。只记录非敏感标识，不保存 token、Cookie、会话或带签名的媒体 URL。
4. 在生成前检查当前平台套餐与导出能力。用户已授权的具体试片可以生成；遇到收费升级或额外购买，不绕过门禁、不录制预览替代下载。

## 生成后的真实状态

使用 `avatar-aroll/provenance.json` 记录独立状态：

| 状态 | 含义 | 可进入阶段 6？ |
| --- | --- | --- |
| `submitted` | 已提交生成 | 否 |
| `preview_ready` | 网页或平台能播放预览 | 否 |
| `source_ready` | 已取得独立源文件，`ffprobe` 读出视频、音频、时长、画幅 | 可进入初检 |
| `verified` | 抽查开头、中段和结尾的口型、发音、人物一致性、音画同步；保存检查记录 | 是 |
| `blocked` | 套餐、权限、生成或下载阻断 | 否 |

源片应保存为 `avatar-aroll/source.mp4` 或保留原格式并在 `provenance.json` 写实际文件名。用 `ffprobe` 读流信息，至少播放和抽看多个时间点；任务成功回执不替代画面检查。发现嘴型、发音或人物漂移时修复或重新生成，不能直接进入合成。

## 汇合到现有剪辑管线

1. 以源片实际音频为时间真值，转写或读取准确字幕，给 `STORYBOARD.md` 回填真实时间戳。数字人语速可能改变原稿时长，不沿用预估时间轴。
2. 按阶段 6 产出 `aroll/` 的字幕和清洗记录。若源片无需清洗，显式记录“检查后跳过”，不要伪造剪辑决策。
3. 从真实字幕和 `STORYBOARD.md` 派生 `EFFECT-BEATS.md`，按现有素材审计、特效库和 Hyperframes 规则制作 B-Roll。数据与产品操作镜头仍需真实证据素材。
4. 交付有声 MP4、SRT/ASS、抽帧证据、源片来源和未验证项。用真人 A-Roll 验证下游时，在文件名和报告中明确标注，不能写成数字人成片。

## 剪映可编辑草稿

- 草稿应分别包含 A-Roll 原视频、字幕、B-Roll/动效素材与音轨；如果某一层只能合成成视频素材，说明该层内部不可逐元素编辑。
- 生成草稿文件、ZIP 完整性和 JSON 引用检查只算 `draft_built`。在安装的桌面剪映中实际打开，确认媒体无丢失、时间轴轨道正确、能修改字幕和素材并导出，才算 `draft_open_verified`。
- 草稿的导出结构随剪映版本变化，接入口播工程前必须逐版本实机验收。若目标机器未安装剪映，只交付草稿候选包并标明 `draft_built`，不宣称剪映已验证。

## 平台门禁与下游验证

- 网页能播放预览但下载需要付费升级或额外权限时，状态停在 `preview_ready`，不是 `source_ready`；不录屏冒充源文件，不绕过门禁。
- 创建数字人形象遇到套餐或权限阻断时，记录阻断原因和时间，不继续往后编造产物。
- 可以用真人 A-Roll 单独验证下游管线（清洗、字幕、动效、合成）。文件名和报告必须标明“管线验证”，不能写成数字人口播成片。
- 草稿候选包只做了结构检查时，状态写 `draft_built`；没有桌面剪映的机器上不宣称已打开验证。
