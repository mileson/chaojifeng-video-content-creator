# 屏录隐私与冗余动作审计

凡素材或现有粗剪含浏览器、桌面、终端、文件管理器或应用界面，阶段 5–8 均读取本文件。已有成片只做局部修改时，也要在受影响区间和最终导出文件上执行对应检查。场景实例见 `data/screen-recording-cases.yaml`；用户当次要求优先。

## 两份清单，先发现再处理

1. **地址候选**：逐段检查顶部地址栏、左下角悬停链接、正文与弹窗、搜索框、工具提示、文件路径、终端、二维码附近文字，以及放大/缩小/滚动后的同一位置。`http://`、`https://`、`www.`、域名、路径、查询参数和偶然出现的 `HTTP/HTTPS` 字样都要进入候选；不能只用字幕、OCR 或固定坐标判断。候选要看真实画面，区分地址与教学概念词。
2. **动作候选**：逐段记录观众实际看到的新信息、口播、鼠标动作和画面状态。滚上又滚回原位置、切换后无目的找位置、等待加载、重复打开同一页面、无新增结果的反复点击、重复解释，都进入候选；静音或键盘声本身不证明片段应保留。

把候选写入项目 `checks/screen_review.json` 或当前版本的等价审计文件。每条至少记录 `source_range_frames`、`timeline_range_frames`、`kind`、`evidence`、`decision`、`reason`、`confidence`、`verification_frames`；记录地址类型与位置，不保存原始敏感 URL、token 或完整私人路径。剪辑后重新映射时间，不能沿用源片秒数冒充成片秒数。

## 地址处理决策

默认主动处理偶然露出的地址，不等用户指出。按以下顺序选择最小且可靠的方式：

1. **片段没有独有操作或讲解**：直接剪掉含地址的多余片段，并检查音频、字幕和画面接点。
2. **片段必须保留，地址只在局部出现**：只在真实出现的帧和区域使用跟背景匹配的纯色、轻度模糊或跟踪遮罩。左下角悬停链接按状态条的实际出现时间贴近底色；顶部地址栏只在它可见时遮盖，页面放大后地址栏已不在画面里就停用；正文里的 `http(s)://`、域名或路径只处理文字所在的小区域，必要时随滚动跟踪。
3. **裁切不影响按钮、步骤和字幕**：可以裁掉边缘地址；若裁切损失演示信息，则回到局部遮罩。遮罩不能盖住标题、操作目标、页面内容或人脸。
4. **地址本身是教学对象**：先判断是否能只展示公开、无个人参数的必要部分；不能安全判断时列为评审候选，不擅自制造虚假示例地址，也不让可识别的私人信息通过。

单独的协议概念词（例如口播正在讲解 HTTP）不等于私人地址；但它若是页面偶然露出的地址残片，默认处理。任何检测器只负责提出候选，最终决定依据源画面和演示目的。

## 多余画面动作处理

比较动作前后的页面位置、可见内容和讲解目标：若画面从状态 A 滚动/切换到 B，又回到 A，期间没有独有信息、关键点击或有效口播，这是高置信的往返动作候选。定位剪点时，保留观众看懂下一步所需的稳定画面和关键动作，通常检查动作前后约 0.4–0.7 秒；这个范围是审看起点，不是强制保留或删除阈值。

- **可主动裁剪**：纯等待、无结果的往返滚动、无独有信息的重复画面，且已确认无有效口播。只压缩无信息区间；有实际操作结果的静默演示不得套固定时长上限。
- **口播重复**：对照真实音频和字幕，优先保留完整且更清楚的一遍；必须按完整句子或动作边界剪音视频并同步字幕。若两遍承载不同细节，或剪后因果不清，先列评审候选。
- **剪后复核**：检查前后画面是否跳到可理解的状态、音节是否完整、字幕是否同步、遮罩和特效是否随时间轴正确移动。

## 双向验收：漏遮与误遮

在**实际导出的最终视频**上验收，编辑器时间线或队列完成提示只能作为中间证据：

1. 每段地址候选核对遮盖区间的前一帧、首帧、中间帧、末帧、后一帧，并补查移动、悬停和转场时刻。确认可识别地址在最终文件中不可读。
2. 每段遮罩同时核对至少一个**不该遮的负样本**；检查遮罩有没有在地址消失后继续覆盖页面。长遮罩尤其要在中间多点抽样，不能只看头尾。
3. 先用 OCR、颜色/形状扫描或接触表定位疑点，再人工看像素；自动扫描通过不能替代目检。检查重点包括浏览器地址栏、左下角状态条、正文、放大视角和所有剪口。
4. 对动作裁剪复看剪口两侧音画、字幕和页面状态。记录已通过范围、仍有疑点与未验证项；没有问题也留下审计结果。

## 扩充场景

遇到新型地址露出或新的冗余动作，先在当前视频完成候选、处理和最终成片核验，再往 `data/screen-recording-cases.yaml` 增加去标识化案例：可观测信号、处理顺序、误判保护、验收方式和来源。未经验证的猜测只标 `candidate`，不能升级为默认自动处理。不要把某条视频的绝对时间、坐标、颜色或私密 URL 当成所有视频的固定规则。
