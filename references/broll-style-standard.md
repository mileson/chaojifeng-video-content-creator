# B-Roll 视觉语言与屏录工艺标准

> 定位：**硬标准**。每个视频工程在 Stage 4 之后生成自己的 `BROLL-STYLE.md`，以本标准为基线，可按选题覆写色彩与元素，但屏录工艺六条与字幕规范不可降级。
> 来源：2026 业界工艺对标（Screen Studio/Recordly 工作流、Vidyard 完播率数据、产品发布视频结构最佳实践）。

## 一、屏录工艺六条（硬标准，所有屏录素材适用）

1. **采集规格**：4K@60fps 采集 → 1080p 成片。保证后期 1.5-2x 推近后 UI 文字依然清晰；全屏 1440p 直出 1080p 会让按钮和下拉文字不可读。
2. **环境卫生**：深浅主题全片统一；隐藏 Dock / 菜单栏 / 通知；遮蔽敏感信息（客户名、token、二维码）；录屏里的业务数据必须像真实业务数据，禁止 "test123"。
3. **光标礼仪**：移动有目的、不游走；**点击前停顿 0.5 秒**让观众视线先到位；光标替换为高清大号版。
4. **自动变焦**：关键交互处 1.5-2x 平滑推近。优先用带自动 zoom 的录制工具（Screen Studio 付费 / Recordly 开源），避免手工逐帧 keyframe。
5. **背景包装**：屏录不满铺——壁纸背景 + 圆角 + 柔和阴影 + 适度 padding（Screen Studio 默认工艺）。
6. **高亮语言**：强调按钮/数字用 HUD 角标 + 描边发光，**禁止红圈红箭头大字报**。

## 二、视觉语言基线（默认风格包：科技场景风）

口播视频的默认基调（可在项目 `BROLL-STYLE.md` 按选题覆写）——与深色屏录素材无缝衔接：

| 角色 | 默认值 | 说明 |
|------|--------|------|
| 底色 | 深石墨/藏蓝渐变（#0d1117→#1a2233） | AI 图背景、屏录壁纸、字卡底 |
| 主发光 | 青色系（#4dd0e1） | 面板描边、虚线网络、HUD 角标 |
| 强调发光 | 珊瑚橙系（#ff7a59） | 关键按钮、数字强调、进度打勾 |
| 元素词典 | 玻璃拟态面板 / HUD 四角短括号 / 发光点状虚线 / 打字机关键词字卡 | AI 图与排版动画共用 |

**关键教训**：AI 概念图的风格必须和相邻屏录镜头同色温——浅色极简插画插在深色屏录中间会跳戏。生成 AI 图前先确认前后镜头的明暗基调。

## 三、字幕规范（硬标准）

- **全片烧录字幕**：大量观众静音观看（信息流 autoplay 场景尤甚）。
- 白字 + 细深色描边，底部安全区，单行 ≤18 字。

## 四、结构节奏标准（Stage 4 自检并入）

- **Pattern Interrupt**：每 ≤60 秒至少一次强刺激（logo 事件 / SFX 爽点 / 章节转场），在分镜表自检中列出各刺激点时间戳与最大间隔。
- **CTA 单一性**：主动作有且仅有一个（如"去官网下载"）；互动问题可保留但降级为收尾彩蛋，禁止两个动作并列。
- **衍生精剪版**：完播率在 60 秒后陡降——主片 >2 分钟时，必须同时规划 60-90 秒精剪衍生版（钩子→核心痛点→最强证据镜→一句话人群→CTA），用于朋友圈/即刻/Product Hunt 等场景。

## 五、AI 概念图多候选评审法（推荐流程）

风格类 AI 图不要一把梭：同一镜生成 2-3 个构图方向的候选 → 按固定评分标准匿名打分（语义命中 / 风格 / 科技感 / 视频可用性 / 情绪匹配，各 5 分）→ 选优归档，落选图留 `archive-` 前缀备查。评分标准先于看图定死，避免先看图再找理由。
